# Hi, I'm Yihan Wu 👋

I build AI agents, desktop apps, and tools for developers, with a focus on making AI useful in everyday work.

我关注 AI 智能体、多智能体协作和桌面自动化，希望让 AI 更好地融入日常工作。

## Currently building

**[OpenAgent](https://github.com/BANG404/openagent)** — a desktop AI agent client built with Tauri, SvelteKit, and Rust, with multi-agent workflows, persistent memory, MCP integrations, and plugins.

Its plugin ecosystem includes a [developer kit](https://github.com/BANG404/openagent-plugin-kit), a [message board for agent collaboration](https://github.com/BANG404/message-board), and [workflow automation](https://github.com/BANG404/openagent-goal).

[Explore OpenAgent](https://bang404.github.io/openagent/) · [Download releases](https://github.com/BANG404/openagent/releases) · [Plugin developer kit](https://github.com/BANG404/openagent-plugin-kit)
